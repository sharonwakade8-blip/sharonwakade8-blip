## About

I'm a **Data Scientist and Machine Learning engineer** who builds end-to-end, production-oriented systems: from problem framing and modelling to interactive dashboards that people can actually use.

- **Engineering-first mindset**: clean pipelines, reproducible experiments, and validated releases (`py_compile`, Streamlit AppTest, live smoke tests).
- **AI / ML expertise**: NLP (NER, clause classification, semantic search), reinforcement learning (DQN / PPO), and gradient-boosted models (LightGBM).
- **Full stack development**: React + Vite + Tailwind front ends paired with Python back ends, orchestrated with Airflow and packaged with Docker.
- **Product engineering mindset**: every project starts with a real-world problem statement and is evaluated against a clear baseline.
- **Research**: published author on the ethical and social implications of AI systems.

## Featured Projects

<details>
<summary><b>LexiGuard AI: Contract Intelligence & Risk Scoring</b></summary>
<br/>

Manual contract review is slow and inconsistent at identifying clauses, entities, and risk. LexiGuard AI is a production-oriented NLP / ML pipeline for automated legal contract analysis.

| | |
|:--|:--|
| **Stack** | Python · NLP · NER · Clause Classification · Semantic Search |
| **Scale** | Trained on the CUAD dataset: 500+ commercial contracts, 41 legal clause categories |
| **Performance** | Key-entity extraction, clause classification, and semantic search in a single pipeline |
| **Security** | Risk scoring surfaces contractual exposure for review |
| **Impact** | Faster, more consistent contract review |
| **Repository** | [github.com/sharonwakade8-blip/LexiGuard-AI](https://github.com/sharonwakade8-blip/LexiGuard-AI) |

The pipeline extracts key entities, classifies clauses across 41 categories, assigns risk scores, and supports semantic search, giving reviewers a structured view of a contract instead of a wall of text.

</details>

<details>
<summary><b>Airline Dynamic Pricing Using Reinforcement Learning</b></summary>
<br/>

Fixed ticket pricing cannot adapt to real-time demand and seat availability. This project trains an RL agent to learn demand-responsive pricing.

| | |
|:--|:--|
| **Stack** | Python · Reinforcement Learning · DQN · PPO |
| **Scale** | Custom simulated airline booking environment |
| **Performance** | Evaluated on revenue, seat occupancy, and pricing behaviour against fixed-price baselines |
| **Security** | Simulation-only environment; no live customer data |
| **Impact** | Demonstrates adaptive pricing strategies over static fares |
| **Repository** | [github.com/sharonwakade8-blip/Airline-Dynamic-Pricing-RL](https://github.com/sharonwakade8-blip/Airline-Dynamic-Pricing-RL) |

A custom environment defines the state, action, and reward functions of airline booking. Training curves and pricing trends are visualized to communicate model performance clearly.

</details>

<details>

| **Scale** | Project and experiment tracking across multiple ML workstreams |
| **Performance** | Recharts-powered analytics with a fast Vite build |
| **Security** | Containerized deployment with Docker |
| **Impact** | One central view of ML projects and experiments |
| **Repository** | [github.com/sharonwakade8-blip/VectorLoom](https://github.com/sharonwakade8-blip/VectorLoom) |

Built with a dark navy theme, Lucide React iconography, and data visualization for analytics, with Python and Airflow supporting the workflow layer.
