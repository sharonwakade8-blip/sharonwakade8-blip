## About

Data Scientist and ML engineer with internship experience in Python, machine learning, and data analysis, focused on shipping production-oriented, end-to-end solutions. I build NLP pipelines, reinforcement learning systems, predictive models, and the full stack dashboards that put them in front of users.

I validate releases with structured testing (`py_compile`, Streamlit `AppTest`, live smoke tests) and care about maintainability, data access, and version control, including designing and deploying a feature store for ML models.

Published AI-ethics researcher, with an international publication on the ethical and social implications of AI systems.

<summary><b>LexiGuard AI — Contract Intelligence & Risk Scoring</b></summary>

<br/>

Production-oriented NLP and machine learning pipeline for automated legal contract analysis. Manual contract review is slow and inconsistent at identifying clauses, entities, and risk; LexiGuard automates it end to end.

| | |
|:--|:--|
| **Stack** | Python, NLP, NER, Clause Classification, Semantic Search |
| **Scale** | CUAD dataset: 500+ commercial contracts, 41 legal clause categories |
| **Performance** | Key-entity extraction, clause classification, and semantic search across contracts |
| **Security** | Designed for sensitive contract data with a production-oriented pipeline |
| **Impact** | Faster, more consistent clause identification and risk assessment than manual review |
| **Repository** | [github.com/sharonwakade8-blip](https://github.com/sharonwakade8-blip?tab=repositories) |

The pipeline extracts key entities, classifies legal clauses, scores contract risk, and supports semantic retrieval, giving reviewers a structured view of each agreement instead of a wall of text.

</details>

<summary><b>Airline Dynamic Pricing Using Reinforcement Learning</b></summary>

<br/>

Fixed ticket pricing cannot adapt to real-time demand and seat availability. This project trains an RL agent to learn demand-responsive pricing policies.

| | |
|:--|:--|
| **Stack** | Python, Reinforcement Learning, DQN, PPO |
| **Scale** | Custom simulated airline booking environment with defined state, action, and reward functions |
| **Performance** | Evaluated on revenue, seat occupancy, and pricing behavior against fixed-price baselines |
| **Security** | Fully simulated environment with no real customer data |
| **Impact** | Demonstrates adaptive pricing that responds to demand and remaining inventory |
| **Repository** | [github.com/sharonwakade8-blip](https://github.com/sharonwakade8-blip?tab=repositories) |

A bespoke environment models booking dynamics, and DQN and PPO agents are benchmarked against static pricing. Training curves and pricing trends are visualized to communicate model behavior clearly.

</details>
